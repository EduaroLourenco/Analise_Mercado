# Análise de Mercado

Análises de mercado interativas de categorias do Mercado Livre, para apresentação a clientes.

- `index.html` — índice e comparativo entre os mercados
- `aditivo_radiador_1l.html` — Aditivo para Radiador 1 L
- `lubrificante_armamentos_200ml.html` — Lubrificante para Armamentos 200 ml

Site estático, sem build: abra o `index.html` ou publique pelo GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / root).

Para criar uma nova análise, veja `PADRAO_REUTILIZAVEL.md`.
